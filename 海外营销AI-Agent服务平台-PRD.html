海外营销 AI Agent 服务平台

产品需求文档（PRD） · 版本 v1.1 · 面向跨境企业的 B2B 海外社媒营销自动化服务站
产品定位：一个面向跨境/外贸企业的 B2B 海外营销自动化服务平台（类比阿里国际站作为企业出海服务入口），以 AI Agent 为核心，覆盖 LinkedIn、Facebook、X（Twitter）、TikTok 等海外社媒的市场研究 → 选题 → 内容生成 → 审核 → 排期 → 发布 → 线索整理 → 效果分析全链路，帮助企业提升获客效率、稳定内容质量、控制人工与模型成本。

1. 背景与目标

观察到的问题

  • 跨境企业的海外社媒营销（LinkedIn、Facebook 等）高度依赖人工：从行业/竞品研究、选题、英文撰写到排期发布、线索回复，环节多、周期长、内容质量不稳定。
  • 营销团队难以同时兼顾"内容产出量"与"品牌一致性"，且线索分散在各社媒平台，无法与 CRM 形成闭环。
  • 缺乏对模型调用成本、人工耗时、有效线索与转化表现的统一度量，难以持续优化。

产品决策

搭建以 AI Agent 为核心的海外营销自动化服务平台，将营销需求转化为可运行、可评估、可迭代的 Agent 任务流，并通过知识库、人工审核、社媒/CRM 对接保障落地。

可观测的期望结果

  • 营销任务可在平台上自动运行，关键节点支持人工审核干预；
  • 生成内容符合品牌定位、产品事实与平台表达习惯；
  • 线索可统一整理并流转至 CRM，内容效果与成本可度量。

2. 范围

2.1 P0（最小完整闭环）

P0 支撑"从配置知识库 → 自动产出并发布内容 → 回收线索与效果"的端到端闭环：

  • FR-1 品牌与产品知识库管理
  • FR-2 AI Agent 营销任务流（研究 / 选题 / 生成 / 排期 / 发布）
  • FR-3 社媒账号管理与内容发布
  • FR-4 人工审核工作流
  • FR-5 线索整理与 CRM 对接
  • FR-6 效果分析看板
  • FR-7 任务日志、异常处理与重试监控
  • FR-8 模型调用成本监控

2.2 P1（增强）

P1 在闭环稳定后扩展：

  • 多语言内容生成（除英文外的小语种）
  • 内容 A/B 测试与自动择优
  • 竞品动态监控与告警
  • 团队细粒度权限与审批流
  • 更多社媒平台（Instagram、YouTube、Pinterest 等）

2.3 明确排除

排除

  • 付费广告投放（Ads）管理——本平台聚焦有机内容营销
  • 电商交易、支付、订单履约闭环
  • 社媒账号的注册与养号
  • 代理企业直接回复客户私信的客服能力（仅做线索提取与分发）

3. 产品模型

3.1 角色

角色说明核心权限
企业管理员平台付费主体，企业账号所有者成员管理、知识库、账号绑定、成本与全量数据查看
营销专员日常营销执行者创建/运行任务、编辑内容、查看线索与效果
审核人内容质量把关者审核、打回、直接编辑待审内容
AI Agent（系统）自动化执行者按任务流执行研究/生成/发布，不自主发布未审核内容

3.2 核心对象

对象定义
知识库条目品牌信息、产品事实、平台表达规范、竞品档案等可被 Agent 检索的事实单元
营销任务一次完整的 Agent 营销活动，包含目标、平台、频率、预算与执行步骤
内容稿件Agent 生成、经审核后发布的单条社媒内容
社媒账号企业绑定的 LinkedIn / Facebook / X（Twitter）/ TikTok 等平台账号
线索从社媒互动中提取的潜在客户信息

3.3 核心用户旅程

入口条件：企业已注册、配置品牌/产品知识库、绑定至少一个社媒账号。

配置知识库→ 绑定社媒账号→ 创建营销任务→ Agent 研究/选题→ Agent 生成内容→ 人工审核→ 排期发布→ 回收线索→ 效果与成本分析

完成证据：内容已发布到目标社媒平台，平台回收互动与线索数据，效果与成本在看板中可查。

关键恢复路径：审核打回 → Agent 依据修改意见重新生成；发布失败 → 自动重试并告警；线索同步失败 → 进入重试队列。

4. 功能需求

FR-1

品牌与产品知识库管理

目的：为内容生成提供事实来源，保障生成内容符合品牌定位、产品事实与平台表达习惯。

触发：企业管理员或营销专员在"知识库"模块新增/编辑条目。

条目类型

类型内容示例用途
品牌信息品牌定位、slogan、核心价值主张、禁用词统一品牌调性
产品信息产品名、功能、参数、卖点、适用场景内容事实依据
平台规范LinkedIn / Facebook / X / TikTok 字数、语气、Hashtag 习惯适配平台表达
竞品档案竞品名称、定位、主打卖点差异化选题

文档批量导入

支持将企业现有文档直接导入知识库，系统自动抽取文本并切分为可检索条目，降低手动录入成本。

项规则
支持格式PDF、Word（.docx）、PPT（.pptx）、Excel（.xlsx）、纯文本（.txt/.md）、网页（URL）
解析方式按格式提取正文与标题层级；PDF 扫描件走 OCR；抽取失败时回退到文件名与外部元数据
切分规则按标题层级 / 段落 / 固定长度（默认 500 字，可配置）切分为条目，保留来源文档引用
单文件限制单文件 ≤ 50MB；单次批量 ≤ 20 个文件 [TBD 可按企业套餐调整]
导入后处理自动归类为"产品信息"或"品牌信息"（用户可改）；状态默认为草稿，用户确认后生效
异常格式不支持 / 解析失败的文件单独列出并标记失败原因，允许重试；不影响其他文件导入

处理规则

  • 每条目字段：标题、正文、适用平台标签（可多选）、来源、更新时间。
  • 条目状态：草稿 → 已生效 → 已归档；仅"已生效"条目可被 Agent 检索。
  • Agent 在生成内容前，按任务目标与平台标签检索相关条目，作为生成上下文。

异常

  • 知识库为空时创建营销任务，系统提示"请先配置品牌/产品知识库"，允许跳过但标记内容质量风险。
FR-2

AI Agent 营销任务流

目的：将营销需求拆解为多步骤 Agent 任务流，实现工具调用、状态管理、记忆、条件分支与人工审核。

触发：营销专员创建任务，设定目标、目标平台、内容频率、预算上限。

任务流步骤

  1. 市场与竞品研究：Agent 调用数据服务，输出行业趋势与竞品内容简报。
  2. 选题：基于研究结果 + 知识库，生成选题列表（含角度、预估互动点）。
  3. 内容生成：按平台规范生成英文内容初稿，附 Hashtag 与配图建议。
  4. 人工审核（见 FR-4）：审核通过进入排期，打回则回到生成步骤。
  5. 排期：设定发布时间（支持批量定时）。
  6. 发布（见 FR-3）：调用社媒 API 发布。
  7. 效果回收：采集曝光、互动、点击等数据（见 FR-6）。

任务状态机

草稿→ 审核中→ 待发布→ 已发布→ 已完成

任意步骤失败 → 失败（自动重试，见 FR-7）；用户主动终止 → 已取消。

记忆与分支

  • 任务内记忆：同一任务内研究结果、选题、修改意见在步骤间共享。
  • 任务间隔离：不同企业、不同任务的上下文互不泄露。
  • 条件分支：审核不通过 → 打回生成；生成内容未命中知识库关键事实 → 自动提示并要求补充。
FR-3

社媒账号管理与内容发布

目的：绑定企业社媒账号并将审核通过的内容发布到目标平台。

账号绑定

  • 支持 LinkedIn、Facebook、X（Twitter）、TikTok 账号 OAuth 授权绑定；P0 覆盖这四个平台。
  • X（Twitter）使用 OAuth 2.0 授权码模式；TikTok 使用官方 Login Kit 授权。
  • 绑定后显示账号名称、平台、授权状态、到期时间；授权失效时标红并提醒重新授权。

发布规则

  • 仅待发布且审核通过的稿件可发布。
  • 支持立即发布与定时发布；定时任务由系统按设定时间触发。
  • 发布结果（成功/失败、平台帖子 URL）回写稿件状态与任务日志。
  • 同一稿件不可重复发布；重复发布需另存为新稿件。

异常

  • 授权过期 / API 限流 → 发布失败，进入重试队列并通知负责人（见 FR-7）。
FR-4

人工审核工作流

目的：在内容发布前由人工把关质量，Agent 不自主发布未审核内容。

稿件状态

待审核→ 审核通过
待审核→ 打回重新生成待审核

审核操作

操作结果后续
通过稿件进入"待发布"可排期发布
打回（必填修改意见）稿件退回 AgentAgent 依据意见重新生成，再次进入"待审核"
直接编辑审核人修改稿件内容保存后进入"待发布"，记录修改人与版本

低风险内容自动通过

为降低人工审核负担，满足以下全部条件的稿件判定为"低风险"，可由系统自动通过并进入"待发布"，无需人工逐一审阅：

判定维度低风险条件
内容事实生成内容命中的知识库关键事实覆盖率 ≥ 设定阈值（默认 80%）
品牌合规未出现品牌禁用词、未偏离品牌定位（由 Agent 自检通过）
敏感内容不含政治、宗教、争议性话题，未触发敏感词库
平台合规字数、Hashtag 数量符合目标平台规范
任务配置该任务已开启"低风险自动通过"开关（由企业管理员配置）
  • 自动通过的稿件仍记录在"已审核"列表，标注"系统自动通过"，审核人可事后抽查与撤销。
  • 不满足低风险条件的稿件一律进入人工审核队列。

规则

  • 审核超时（默认 24 小时，可配置）向审核人发送提醒。
  • 打回次数达到上限（默认 3 次，可配置）后任务标记为失败，通知营销专员介入。
FR-5

线索整理与 CRM 对接

目的：从社媒互动中提取潜在客户线索，并流转至企业 CRM。

线索来源

  • LinkedIn、Facebook、X（Twitter）、TikTok 私信、评论、主页访问表单中提取的潜在客户信息。

线索字段

字段说明
姓名 / 公司 / 职位从互动内容与公开资料提取
联系方式邮箱、电话（若可获取）
来源平台 / 来源内容关联到具体平台与已发布稿件
意向度Agent 依据互动内容判定（高/中/低）
状态新线索 / 已跟进 / 已转化 / 无效

流转规则

  • 新线索进入线索池，可人工分配给跟进人。
  • 支持通过 API / Webhook 将线索推送到外部 CRM；推送失败进入重试队列。
  • 同一联系人在同一企业内去重，合并为一条线索并记录来源。
FR-6

效果分析看板

目的：度量内容表现、线索质量与转化，支撑持续优化。

指标维度

内容指标

  • 曝光量、互动量（点赞/评论/分享）、点击率
  • 按平台、任务、稿件聚合

线索与转化指标

  • 新增线索数、有效线索率、转化率
  • 按来源平台、内容、时间聚合

筛选与导出

  • 支持按平台、任务、时间范围筛选；支持导出 CSV。
[Assumption, TBD] 转化率需依赖 CRM 回传的转化数据；若企业未对接 CRM，转化率指标暂以"已跟进/已转化"人工标记为准。
FR-7

任务日志、异常处理与重试监控

目的：保障任务可观测、可恢复、可维护。

任务日志

  • 每个步骤记录：开始/结束时间、输入、输出摘要、耗时、状态。
  • 日志保留期限：[TBD]（建议不少于 90 天）。

异常与重试

场景处理
模型调用失败 / 超时自动重试（默认 3 次，指数退避）
社媒 API 限流 / 授权失效重试 + 通知负责人重新授权
CRM 推送失败进入重试队列，超过上限后人工介入
重试仍失败任务置为失败，通知负责人并保留上下文

运行监控

  • 提供任务运行状态视图（运行中 / 等待审核 / 待发布 / 失败），支持按状态筛选与快速介入。
FR-8

模型调用成本监控

目的：度量 AI 投入，支撑成本控制与 ROI 评估。

  • 记录每次模型调用的 token 消耗与费用，关联到具体任务与稿件。
  • 按任务 / 平台 / 时间维度汇总成本。
  • 计算单条内容成本、单线索成本，在看板与 FR-6 效果指标并列展示。
  • 支持设置任务级成本上限，达到上限时暂停生成并通知负责人。
[Assumption, TBD] 成本核算口径按实际调用的模型定价计算；多模型混用场景按各模型实际消耗分别统计后汇总。

5.1 角色权限矩阵

能力企业管理员营销专员审核人
成员与权限管理✅——
知识库管理✅✅查看

内容审核✅查看✅
社媒账号绑定✅——
线索管理与分配✅✅查看
效果与成本看板全量本人/本任务查看

5.2 对象状态汇总

对象状态说明
知识库条目草稿 / 已生效 / 已归档仅"已生效"可被检索
营销任务草稿 / 审核中 / 待发布 / 已发布 / 已完成 / 失败 / 已取消见 FR-2 状态机
内容稿件待审核 / 审核通过(待发布) / 已发布 / 打回 / 失败见 FR-4
线索新线索 / 已跟进 / 已转化 / 无效见 FR-5

5.3 审计与通知

  • 所有审核、发布、删除、权限变更操作记录审计日志（操作人、时间、对象、变更内容）。
  • 通知触发：待审核提醒、审核超时、发布失败、任务失败、成本达上限、线索同步失败。
  • 通知渠道：站内通知 + 邮件 [TBD 企业微信/钉钉是否接入]。

6. 开放问题（待确认）

  1. CRM 对接：首批支持哪些 CRM（如 HubSpot、Salesforce、纷享销客）？是否需要内置轻量 CRM？
  2. 多租户与数据隔离：平台服务多企业时，数据隔离与合规（如 GDPR）的边界需法务确认。
  3. 成本上限：任务级成本上限的默认值与超额处理策略（暂停/降级模型/通知）。
  4. 语言范围：P0 是否仅英文，小语种纳入 P1 的优先级？
  5. 文档导入限制：单文件 50MB / 单次 20 个的默认限制是否需按企业套餐差异化？

已确认决策（v1.1）：P0 平台纳入 LinkedIn、Facebook、X（Twitter）、TikTok；知识库支持文档批量导入；低风险内容自动通过审核。
